# Architecture Decision Records (system-wide)

This directory holds **system-wide** ADRs — decisions that span more than one
package. Package-scoped decisions live in `packages/<name>/docs/adr/` instead;
use the narrowest scope that fully contains the decision.

Format and numbering convention: see
[`prefapp/skills`’s `domain-modeling/ADR-FORMAT.md`](https://github.com/prefapp/skills/blob/main/skills/domain-modeling/ADR-FORMAT.md)
(sequential `0001-slug.md`, authored lazily via `/domain-modeling`).
